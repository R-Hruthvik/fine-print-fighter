# Rebuttal Lab demo storyboard

Status: pre-production script. The live model and its output have not been recorded or validated yet. Keep the filmed demo under three minutes and make the central value visible within the first 30 seconds.

## Main path (about 75 seconds)

| Time | Show | Narration |
| --- | --- | --- |
| 0:00–0:08 | Open the form with the fictional subscription dispute. Keep the fiction notice visible. | “A billing dispute usually starts with two conflicting stories: yours and the company’s.” |
| 0:08–0:18 | Paste the consumer evidence and the separate invented company rejection. Submit. | “We give the rejection its own field so the investigation starts from what the company actually said. This example is fictional.” |
| 0:18–0:30 | Show real investigation actions and a retained company-policy source. | “Nemotron selects a bounded policy question; our app runs the search and checks every passage before showing it.” |
| 0:30–0:42 | Show one source-backed objection and the requested missing exhibit. | “Here is the strongest company-side explanation we could trace, plus the exact evidence gap.” |
| 0:42–0:55 | Add the fictional cancellation confirmation as a separate exhibit and recheck. | “Now we add a confirmation. A document match is only a review suggestion; it does not establish a refund right.” |
| 0:55–1:15 | Show the checked excerpt, retained source, revised letter, and remaining uncertainty. | “The record and draft change, while unresolved conditions stay visible. Nothing is sent automatically.” |

## Failure path to capture if time permits

Run a second analysis with an irrelevant document, such as a generic welcome email. The desired behavior is an exact excerpt only if the reviewer finds a passage that may address the objection; otherwise the objection stays unresolved and the UI does not label the document as resolving it. Also show one unsupported hypothesis or a search outage with its warning. Do not edit the response to hide an unfavorable result.
